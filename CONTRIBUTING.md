# 🤝 Contributing to medel/translator

Thanks for taking the time. This is a small, dependency free library, so the
workflow is simple too.

## 🧰 Setup

```bash
git clone https://github.com/davidmedeel/translator.git
cd translator
composer install
composer test
```

There is no build step. The package ships as plain PHP.

## ✅ Before opening a pull request

```bash
composer test              # 179 assertions, public API and guarantees
composer test:acceptance   # markup, entities and emojis survive
composer test:i18n         # data integrity and translation quality
composer benchmark         # only if you touched the hot path
```

All of them run **offline**. If any of them needs the network, that is a bug.

## 📏 Style

* PSR-12, 4 spaces, `declare(strict_types=1);` in every file.
* Comments explain **why**, not what. The interesting decisions are documented in
  the README (section *Writing a good glossary*) and next to the code.
* No new runtime dependencies. `php`, `ext-json` and `ext-mbstring` only.
* Keep the public API backwards compatible. New options are optional and default
  to the current behaviour.

## 🌍 Adding or improving a dictionary

The most valuable contributions are usually dictionary entries.

1. **Store whole sentences**, not isolated words. Word by word translation cannot
   fix word order.
2. **One entry per HTML text node.** Nodes are translated separately, so a phrase
   that crosses a tag can never match.
3. **Keep the value free of trailing punctuation** (`..` and `,,` are the usual
   symptom) and of articles that live in another node (`Die Die`).
4. **Add the brand to `keep`**, multi word entries included, or it will be half
   translated.
5. Run `php tools/refresh.php` afterwards if you touched a hub table, then
   `composer test:i18n`.

## 🐛 Reporting a bug

Please include:

* the input (HTML, entities and all),
* the target language and the options you passed,
* what you got,
* what you expected,
* PHP version and operating system.

A failing case is best added to `tests/fixtures/`, so it stays fixed.

## 🚫 Out of scope

* Calling any translation API. That defeats the purpose of this package.
* Shipping dictionaries that were generated by machine translation without
  review. Untranslated output is the safe failure mode here, not wrong output.
